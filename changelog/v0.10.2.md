# 📦 Unla v0.10.2

## 🐞 修复

- 兼容 Apifox 导出的 OpenAPI 3.0 schema 引用和描述。
- 导入文件标题为“默认模块”时，提示输入服务名称。
- 为导入的工具默认添加 Accept-Encoding: identity，并支持带连字符的请求头参数。
- 防止本项目的版本标签触发上游镜像和 Helm 仓库发布。

## 🐞 Fixes

- Accept Apifox OpenAPI 3.0 schema references with descriptions.
- Prompt for a service name when the imported title is 默认模块.
- Default imported tools to Accept-Encoding: identity and support hyphenated header parameters.
- Prevent this fork from publishing to upstream image and Helm repositories.
